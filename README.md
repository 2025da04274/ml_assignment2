# ML Assignment 2 — Classification Model Comparison & Streamlit Deployment

## a. Problem Statement

The goal of this assignment is to build, evaluate, and compare multiple classification
algorithms on a real-world dataset, and to deploy an interactive Streamlit web application
that lets a user upload test data, select a trained model, and view its performance
(evaluation metrics, confusion matrix, and classification report).

## b. Dataset Description

**Dataset:** Breast Cancer Wisconsin (Diagnostic)
**Source:** Built into scikit-learn (`sklearn.datasets.load_breast_cancer`), originally from the UCI Machine Learning Repository.
**Task:** Binary classification — predict whether a tumor is malignant (0) or benign (1) from digitized image measurements of a breast mass.
**Size:** 569 instances, 30 numeric features (mean, standard-error, and "worst" values of 10 measurements: radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, fractal dimension).
**Split:** 80% train (455 rows) / 20% test (114 rows), stratified on the target class. The 114-row test split is saved as `test_data.csv` and is what the Streamlit app expects to be uploaded.

This satisfies the assignment's minimum requirements (≥12 features, ≥500 instances).

## d. Models Used

All 5 models were trained on the same 80/20 train/test split of the dataset above, with features standardized using `StandardScaler` (fit on train only).

### Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Best performer here — this dataset separates almost linearly after scaling, which suits a linear decision boundary well; highest accuracy, F1, and MCC of all five. |
| Decision Tree | Weakest of the five — a single unpruned tree overfits the training split, hurting generalization to the test set (lowest accuracy/AUC/MCC). |
| kNN | Strong, consistent performance; benefits directly from feature scaling since it relies on distance. |
| Naive Bayes | Middling accuracy despite a high AUC — its independence assumption between features is violated here (many measurements are correlated), which hurts hard classification even though ranking (AUC) stays strong. |
| Random Forest (Ensemble) | Matches kNN on accuracy/F1 but edges close to Logistic Regression on AUC — averaging many trees fixes the single Decision Tree's overfitting problem. |
| **Overall Winner for this dataset** | **Logistic Regression** — highest accuracy (0.9825), F1 (0.9861), and MCC (0.9623) among all five models. |
